# Skills

Skills are Markdown procedures for project work that you do again. Examples: how to run the tests, how to release, how to check a migration. The lead agent and its sub-agents read them. The app shows them. Nothing runs them.

Put one `.md` file for each skill directly in this folder. Use `../templates/skill.md`. Each `.md` file in this folder is a skill, except this README. The default `status` in the frontmatter is `active`.

When you use a skill, write its id in the log line, for example `Ran SKILL-001: all tests pass.` The Skills page then shows where the skill was used.

Write skills in ASD-STE100 Simplified Technical English (see `../WRITING.md`).
