The plan for the disks

The installer measured the speed of each disk. The fastest disk gets the system. The other disks become storage tiers for your apps and databases.

Result

System NidaOS and its updates Performance databases and fast apps Standard large data, backups, default

Who can come in

NidaOS has no default password. The administrator signs in with an SSH key. Remote Desktop gets its own password.

Other computers find it as nidaos.local

Installing NidaOS

You can leave the computer. The installation needs approximately 6 minutes. The computer restarts at the end.

  • Erase the disks and make the partitions
  • Copy the system image
  • Prepare the storage tiers
  • Make the administrator and set the access
  • Install the boot loader
NidaOS is installed. Remove the installation media, then restart.
