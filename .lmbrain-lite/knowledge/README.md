# Knowledge Base

The lead agent keeps short pages here, with evidence. Start with these pages:

- `architecture.md`: the components, their limits, and the data flows.
- `codebase-map.md`: the important directories and their contents.
- `setup-and-run.md`: the local installation, the commands, and the checks.
- `integrations.md`: the external services and interfaces. Never put credentials here.
- `glossary.md`: the words of the project.

Use Markdown and `[[wikilinks]]`. Link to paths and explain the intent. Do not copy code: a copy becomes old.

Write all pages in ASD-STE100 Simplified Technical English (see `../WRITING.md`). The Code Index includes these pages, so agents can find them with `tokensave_search`.
