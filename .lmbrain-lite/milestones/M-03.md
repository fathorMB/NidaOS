# M-03 — App hosting from GitHub repositories

## Outcome

The operator adds an app from a GitHub repository and NidaOS keeps it in operation. The operator sees the deploys, changes the settings and goes back to an older version.

## Tasks

- [x] T-01 Carve the app controller out of GitStack core and remove the parts for repositories and teams
- [x] T-02 Add the data model of an app: source, port, health check, limits, variables and secrets
- [x] T-03 Deploy an app version on k3s with a health check and keep the version before on failure
- [x] T-04 Keep the last five versions and add the rollback to one of them
- [x] T-05 Add the folders that stay, on a storage tier, and the move to a different tier
- [x] T-06 Give each app an address in the home network with a certificate
- [x] T-07 Give each app a name that the other apps can use
- [x] T-08 Add the app commands to the API and to the nida command
