# M-02 — Platform core: one service for state, live metrics and live logs

## Outcome

NidaOS has one core service with an API. The service gives the state of the computer, and the metrics and the logs as a live stream. Each interface and the nida command read from it.

## Tasks

- [x] T-01 Make the Go project of the core service from the structure of GitStack core
- [x] T-02 Write the core service with the API for the state of the computer, the disks and the storage tiers
- [x] T-03 Add the live stream of the metrics for the computer and for each workload
- [x] T-04 Add the live stream of the logs with the source and the level of each line
- [x] T-05 Keep the logs for 30 days and give a search in the old lines
- [x] T-06 Add the sign-in for the owner and the tokens for programs
- [x] T-07 Write the nida command for the status, the metrics and the logs
- [ ] T-08 Add the core service to the image and test it in the virtual machine
- [ ] T-09 Write the description of the API for the persons that make the interfaces
