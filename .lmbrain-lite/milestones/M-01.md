# M-01 — Feasibility proof of the Fedora bootc base

## Outcome

The operator knows, from tests in a virtual machine, if Fedora bootc can be the base of NidaOS. A report gives a go or no-go decision for each requirement.

## Tasks

- [ ] T-01 Write the scripts that make a UEFI virtual machine with three virtual disks on Hyper-V
- [x] T-02 Write the minimal image recipe (Containerfile) from Fedora bootc
- [x] T-03 Build the image and an installer ISO in GitHub Actions
- [x] T-04 Install the image in the virtual machine and start it
- [x] T-05 Add k3s to the image and run a test pod on two storage classes on two disks
- [ ] T-06 Add a minimal desktop and connect to it from Windows with Remote Desktop
- [x] T-07 Publish a new image version, update the virtual machine, then go back to the old version
- [x] T-08 Prove that a script in the installer can select the target disks from a computed plan
- [x] T-09 Write the feasibility report with the results, the problems and the go or no-go decision
- [x] T-10 Write an automatic installation test in QEMU with one hard disk and two solid-state disks
