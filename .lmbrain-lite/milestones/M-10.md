# M-10 — Internet gateway on a Raspberry Pi

## Outcome

The operator opens the selected apps and the console from the internet through a small gateway with sign-in. The home router opens no port.

## Tasks

- [ ] T-01 Decide how the gateway gets its public address with balena and examine the limits
- [ ] T-02 Write the gateway service and deploy it on a Raspberry Pi with balena
- [ ] T-03 Connect the gateway to NidaOS with a pairing code and a private link
- [ ] T-04 Add the sign-in on the gateway for the owner, the persons and the groups
- [ ] T-05 Send the name of the person to the app in a signed header
- [ ] T-06 Apply the access choice of each app: home network, public with sign-in, public
- [ ] T-07 Pass the live streams of the metrics and the logs through the gateway
- [ ] T-08 Test the access from the internet to an app and to the console
- [ ] T-09 Make the gateway page of the console from the mockup, with the live state of the link

## Notes

Mockup: `design/console` (Gateway, the Access tab of an app). Decisions: D5 and D8.

Decision D15: the gateway does not pass Remote Desktop.
