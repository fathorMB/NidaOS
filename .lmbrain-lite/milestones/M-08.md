# M-08 — Monitoring desktop

## Outcome

The operator connects with Remote Desktop and sees the NidaOS desktop: the monitor, the terminal, the files and the logs, all with live data.

## Tasks

- [ ] T-01 Make the frame of the GNOME extension and set the GNOME version in the image
- [ ] T-02 Start the extension automatically for the remote session and hide the standard GNOME parts
- [ ] T-03 Make the monitor screen with the live metrics, the storage tiers and the workloads
- [ ] T-04 Make the dock, the terminal window and the power dialog
- [ ] T-05 Make the file program as a GNOME program, with the storage tiers and the app that uses each folder
- [ ] T-06 Make the log program as a GNOME program, with the sources, the filters and the search
- [ ] T-07 Set the Remote Desktop password at the installation and test the connection from Windows
