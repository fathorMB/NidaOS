# M-07 — Installer with the disk planner

## Outcome

The operator installs NidaOS from a USB key with the six steps of the mockup. The installer measures the disks, proposes the plan and erases only after a confirmation.

## Tasks

- [ ] T-01 Make the frame of the custom installer program that starts in full screen from the installation media
- [ ] T-02 Measure the speed of each disk and compute the plan with the reason for each role
- [ ] T-03 Make the welcome step and the disk step, with the change of roles by hand
- [ ] T-04 Make the access step and the network step
- [ ] T-05 Make the review step with the confirmation by the computer name
- [ ] T-06 Make the installation step with the progress and the addresses at the end
- [ ] T-07 Keep the installation without questions for the automatic tests
- [ ] T-08 Test the installer in the virtual machine with different sets of disks
- [ ] T-09 Make the partitions of the plan and install with bootc install to-filesystem, without Anaconda
- [ ] T-10 Add the owner to the group nida, and set the one owner password for nida-core and Remote Desktop

## Notes

Mockup: `design/installer`. Decisions: D6 and D7. The proof of M-01 has the first planner: `installer/rootfs/usr/libexec/nidaos/nida-plan.sh`.

Decision D12: custom installer program. Decisions D32 (web page in a kiosk browser), D33 (bootc install without Anaconda) and D34 (one owner password).
