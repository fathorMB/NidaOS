# M-04 — Managed databases

## Outcome

The operator adds a PostgreSQL database in one step. NidaOS operates it, makes the backups and connects it to the apps.

## Tasks

- [x] T-03 Connect a database to an app and give the connection text as a variable
- [x] T-04 Permit only the connected apps to get to a database, with a switch for the home network
- [x] T-05 Make the daily backups, keep them for a set time, and make a backup on demand
- [x] T-06 Restore a backup into a new database
- [x] T-07 Add the small version update with a backup before it
