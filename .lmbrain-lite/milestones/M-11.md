# M-11 — Updates, rollback and security

## Outcome

NidaOS gets signed updates from a registry and can go back to the version before. The system runs with SELinux on and without the shortcuts of the feasibility proof.

## Tasks

- [ ] T-01 Publish the image to a registry with a version number and a signature
- [ ] T-02 Download and verify an update, then wait for the approval of the operator
- [ ] T-03 Install an update with a restart and keep the version before for a rollback
- [ ] T-04 Run the installer and the system with SELinux on, with the rules for k3s
- [ ] T-05 Remove the sudo rule without password and review each service that listens on the network
- [ ] T-06 Make a backup of the settings of NidaOS and restore it on a clean installation
- [ ] T-07 Test an update and a rollback in the virtual machine with apps and databases in operation
- [ ] T-08 Make a local build and test cycle that is shorter than the 30 minutes of the full cycle
