# M-09 — Agent access

## Outcome

An agent such as Claude Code or Hermes manages NidaOS with the same commands as the console. Rules tell what the agent can do without the approval of the operator.

- [x] T-03 Add the rules: what an agent can read, what it can change, what needs an approval
- [x] T-04 Show an approval request to the operator in the console and wait for the answer
- [x] T-05 Write the instructions that an agent reads before it manages NidaOS
