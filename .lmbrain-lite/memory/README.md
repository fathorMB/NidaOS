# Project Memory

Project Memory keeps short facts, with evidence, about other local Git repositories that are useful to this project. The lead makes the records with `lite_memory_remember`. The Project Memory page is read-only.

The kit owns `README.md`. The project owns all other files in `memory/`, and `projects/MEM-NNN-*.md` too. A kit migration never replaces them. A record moves with the project. Its local path is only a hint for one machine. When a remote is available, the normalized remote identifies the repository.

The lead can remember an examined repository only in one condition. Approved work must take the lead to the repository, and the lead must find an important fact that stays valid, with an evidence path. The lead must not search disks, guess, copy secrets, or change the external checkout. Sub-agents report observations to the lead. They do not write memory.
