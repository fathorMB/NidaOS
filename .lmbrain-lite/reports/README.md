# Reports

This folder has optional snapshots and summaries. Reports are not the source of truth. The milestones, the log and the note are the source of truth.

`lmbrain-kit-feedback.md` is different. It is an append-only report about LMBrain Lite itself, with typed fields. The lead agent writes it with `lmbrain_feedback_record`. Give it to the LMBrain team when you ask for changes to the kit or the app.
